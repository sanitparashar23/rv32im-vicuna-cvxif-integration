upstream projects (Jeffrey Core and Vicuna). This document states plainly
what is original integration/design work versus unmodified upstream code,
so the scope of contribution is clear without needing to dig through file
headers or commit history.

## Debugging and root-cause analysis

Four hardware/tooling bugs were found, root-caused, and fixed during
development. Full writeups with RTL line references, log excerpts, and (for
one) waveform-level proof are in [`docs/debug-notes.md`](docs/debug-notes.md):

- **X-propagation into Vicuna's LSU** -- three undriven CV-X-IF response
  fields (`exc`, `exccode`, `dbg`) resolved to `X` and stalled the
  coprocessor after one memory transaction.
- **Memory layout mismatch** -- an incorrect `d_mem.hex` address layout
  caused array B reads to alias into array A.
- **A `vredsum.vs` race condition, and why the final kernel avoids it** --
  traced a reduction-result race to a vector-register-file read happening
  before a multi-cycle reduction had committed, then discovered (via direct
  RTL inspection, confirmed with a waveform capture down to the exact
  nanosecond) that the final kernel's correctness depends on a genuine
  hardware feature: a scalar-register writeback bypass (`v_xreg_we`) that
  lets Vicuna write results directly into the scalar register file when a
  vector instruction's destination register number coincides with a GPR
  number.
- **A Vicuna/Xcelium port-count mismatch** -- an array-size elaboration
  error caused by a simulator-specific SystemVerilog parsing difference.

## What is unmodified upstream code

For completeness: [`rtl/scalar_core/`](rtl/scalar_core/) (25 files) and
[`rtl/vector_coproc/`](rtl/vector_coproc/) (21 files) contain unmodified
Jeffrey Core and Vicuna source respectively, used as pre-verified IP rather
than re-implemented. This is a deliberate scope decision, stated directly
in the testbench header
([`tb/rv32im_top_tb.sv`](tb/rv32im_top_tb.sv)): the goal of this project is
MAC-operation acceleration via coprocessor integration, not re-verification
of already-verified open-source cores.
